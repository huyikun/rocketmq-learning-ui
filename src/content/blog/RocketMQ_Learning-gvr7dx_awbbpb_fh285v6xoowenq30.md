**<font style="color:#2F8EF4;">10 月 28 日，北京将迎来开源行业的一场重磅盛会——2025 OSCAR 开源产业大会。</font>**

<font style="color:rgba(0, 0, 0, 0.9);">本次大会汇聚全球开源领域的思想领袖、技术专家、企业高管以及创新实践者，围绕开源技术的未来、产业创新及生态协同展开深度讨论。</font>

<font style="color:rgba(0, 0, 0, 0.9);">大会将围绕人工智能开源、软件供应链安全、开源商业化等多个核心议题展开深度对话，通过顶级专家的演讲、精彩的分论坛以及技术展示，与会者将获得关于开源技术的最新洞察和行业趋势，并探索开源技术如何在数字化转型、行业创新及社会价值创造中发挥关键作用。</font> 

<font style="color:rgba(0, 0, 0, 0.9);">现在，我们诚挚邀请您参与 OSCAR 开源产业大会，与开源人相聚，与创新者同频，一起探索开源技术的发展，共同见证开源生态的繁荣。</font>

## <font style="color:rgb(0, 0, 0);">关于 OSCAR</font>
<font style="color:rgba(0, 0, 0, 0.9);">“OSCAR 开源产业大会”是由中国通信标准化协会主办，中国信息通信研究院承办，中国信息通信研究院云计算开源产业联盟、金融行业开源技术应用社区、通信行业开源社区、科技制造开源社区、汽车行业开源社区、可信开源社区共同体、可信开源合规计划支持的开源领域顶级盛会。</font>

<font style="color:rgba(0, 0, 0, 0.9);">大会旨在汇聚全球开源领域的专家、学者、企业代表及社区成员，共同探讨开源技术的最新趋势、治理实践，以有效应对技术风险、法律合规、供应链韧性和人才短缺等挑战，从而寻求推动中国开源生态健康、有序发展的策略，促进开源与产业深度融合，为全球开源事业的繁荣贡献中国的智慧与力量。</font>

## <font style="color:rgb(0, 0, 0);">开源项目及商业化论坛 -  Apache RocketMQ 议题</font>
<font style="color:rgba(0, 0, 0, 0.9);">AI 应用的高延迟、长周期、强状态和资源密集等特性，对底层基础设施提出了前所未有的工程挑战。</font>

<font style="color:rgba(0, 0, 0, 0.9);">传统消息队列在应对 AI 原生（AI-Native）场景的动态性、状态性和资源敏感性方面已显局限，面对这一变革，ApacheRocketMQ 完成了战略性升级，从传统消息中间件演进为</font>**<font style="color:rgba(0, 0, 0, 0.9);">面向 AI 时代的消息引擎</font>****<font style="color:rgba(0, 0, 0, 0.9);">。</font>**

<font style="color:rgba(0, 0, 0, 0.9);">本次分享将介绍如何基于 Apache RocketMQ 的新特性构建异步化 Multi-Agent 系统，深入探讨 Agent 间的异步通信、上下文隔离、状态恢复与任务编排机制，并通过实际案例展示如何利用 RocketMQ 实现 Multi-Agent 的任务调度。</font>
